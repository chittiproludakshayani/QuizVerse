# Machine Learning Driven Crop Yield Prediction with NLP-Based Insight

This Flask web application demonstrates the integration of machine learning for crop yield prediction and NLP for extracting insights from textual data.

## Features

- **Home Page**: Overview of the project.
- **Crop Yield Prediction**: Simple form to input soil and weather data for best crop recommendation.
- **Farmer Feedback**: Collect farmer feedback, crop notes, and field reports.
- **Smart Agriculture Advisor**: Analyze past reports and feedback to provide suggestions.
- **NLP-Based Insight**: Analyze text input for basic insights.

## Installation

1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `python app.py`
3. Open http://127.0.0.1:5000/ in your browser.

## Technologies

- Flask
- scikit-learn (for ML)
- NLTK (for NLP)
- HTML/CSS for frontend
